SIXTH DEGREE RUNELITE - DEVELOPMENT BUILD

This ZIP is used for private testing before a Plugin Hub release.

1. Extract the entire ZIP to a folder.
2. Double-click run-sixth-degree.bat.
3. Log into RuneScape normally in the RuneLite window that opens.
4. Open the Sixth Degree sidebar panel.

The launcher uses the Java runtime installed with the normal RuneLite Windows launcher. If that is unavailable it falls back to a system Java runtime.

Access states:
- Non-Sixth Degree account: recruitment screen and Discord invite.
- Sixth Degree account, Discord not linked: Connect Discord screen.
- Sixth Degree account + authorised Discord Clan Member role: member panel unlocked.

Development API:
https://amnesty-bootlace-poach.ngrok-free.dev/runelite/v1/

Do not distribute development builds as a normal clan release.
